# Project Title  
simulator_codingplatform_integration
# Overview 
This repository is intended to serve as a tutorial for beginners to connect Aspen HYSYS with coding platforms like Python and MATLAB, and carry out customization tasks.
# Features 
1. Connecting Aspen HYSYS with Python and MATLAB
2. Retrieving major HYSYS objects like streams, unit operations, and properties
3. Retrieving backdoor variables from HYSYS
4. Finding built-in methods and ordered arguments of HYSYS objects
5. Using built-in methods to modify HYSYS objects
6. Sample functions to show how to use the above features to carry out more complex tasks like TEA.
# Usage 
Every file in the repository is designed to run stand-alone. Read the comments in the individual files to make changes to default methods.
